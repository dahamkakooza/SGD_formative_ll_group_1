# SDG 3 Indicator Text Classification

ALU ML Techniques I - Group Assignment 2 | Group 1: Nick-Lemy Kayiranga, Akachi Nwanze, Daham Kakooza

Multi-label classification of text documents by the indicators of Sustainable
Development Goal 3 (Good Health and Well-being). A document can belong to zero,
one, or several of the 27 indicators at once. The primary metric is Hamming Loss
(lower is better), with micro and macro F1, precision, and recall reported
alongside it.


files are ignored in `.gitignore`).

## How to Run

### Prerequisites

- Python 3.10+
- The two CSV files in `data/` (provided with the assignment)
- Optional: GloVe 6B vectors for Experiment 7 (the notebook downloads them
  automatically on Colab; without them that one experiment is skipped)

### Setup (Google Colab, recommended)

The notebook is built for Colab and detects it automatically.

1. Open `notebooks/sdg3_classification.ipynb` in Colab.
2. Put the two CSV files in `/content/data/`.
3. Run the cells from the top. The first cell installs the extra packages and the
   second downloads the NLTK resources. Colab may restart once after the install;
   if it does, run again from that cell.

### Setup (local: Linux / macOS)

```
python3 -m venv .venv
source .venv/bin/activate
pip install pandas numpy scikit-learn matplotlib seaborn joblib tqdm
pip install -r requirements.txt
jupyter lab
```

### Setup (local: Windows)

```
python -m venv .venv
.venv\Scripts\activate
pip install pandas numpy scikit-learn matplotlib seaborn joblib tqdm
pip install -r requirements.txt
jupyter lab
```

The core packages (pandas, numpy, scikit-learn, matplotlib, seaborn, joblib,
tqdm) come pre-installed on Colab, so they are not pinned in `requirements.txt`
to avoid version conflicts. Locally the notebook reads the data from the `data/`
folder in this repo.

## Run Order

There is a single notebook. Run it top to bottom; the sections run in order:

1. Environment setup and data loading
2. Exploratory data analysis (label frequency, co-occurrence, text length, types)
3. Preprocessing and train/validation split
4. Feature engineering (BoW, TF-IDF, GloVe, Sentence-Transformer)
5. The 10 experiments
6. Results tables and figures
7. Inference on the test set, written to `artifacts/test_predictions.csv`

The Sentence-Transformer and GloVe experiments are the slowest parts; the sparse
TF-IDF and bag-of-words experiments run in seconds.

## Dataset

- Devex SDG 3 indicator dataset (provided with the assignment)
- `Devex_train.csv`: around 3,000 labelled documents, targets in columns
  `Label 1` to `Label 10`, 27 unique indicators after cleaning
- `Devex_test_questions.csv`: same text columns, no labels, used only for the
  final predictions
